## Convenção

- documentos com `> Status: documento histórico` ou `> Status: snapshot histórico` não descrevem o runtime atual
- planos antigos, demos datadas, validações pontuais e propostas não implantadas devem ser lidos como arquivo histórico
- quando um documento continuar operacional, ele deve evitar referências a arquitetura já removida
